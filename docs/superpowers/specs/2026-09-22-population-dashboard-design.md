# 浦添市 人口ピラミッド・推移ダッシュボード 設計

## 背景・目的

浦添市が毎月公開する「指定区別年齢別男女別人口調（全体）」PDFを自動収集する
パイプライン（`scripts/urasoe_population.py` + GitHub Actions、既存実装済み）
がある。このデータを使い、GitHub Pagesで無料公開できる静的Webダッシュボード
を作る。バックエンドサーバーは持たず、既存のCSVをそのままクライアント側で
読み込んで可視化する。

## スコープ

含む:
- 年齢別人口ピラミッド（男女別、年月切り替え）
- 年少人口(0-14)・生産年齢人口(15-64)・高齢人口(65+)の月次推移グラフ
- 選択年月のサマリー数値（総人口・高齢化率）
- GitHub Pagesでの静的サイト公開

含まない（将来検討）:
- 将来人口予測・シミュレーション
- 他の自治体オープンデータとの統合
- 検索・API提供機能

## アーキテクチャ

- 完全に静的なHTML/CSS/JS（ビルドツール・フレームワーク不使用、CDN経由でライブラリ読込）
- グラフ描画: Chart.js（CDN）
- CSVパース: PapaParse（CDN）
- データソース: `data/population_by_age.csv`（同一リポジトリ内、相対パスでfetch）
- 公開: GitHub Pages（リポジトリの `docs/` フォルダ、または `gh-pages` ブランチ経由）
  - 本設計では `docs/` フォルダ配信方式を採用（ブランチ運用が不要でシンプル）

### ディレクトリ構成（サイト部分）

```
docs/
  index.html
  app.js          # データ取得・状態管理・グラフ更新のエントリポイント
  style.css
```

（`docs/superpowers/specs/` は設計ドキュメント置き場で、`docs/` 直下の
`index.html`・`app.js`・`style.css`・`data/` とはパスが競合しない。
GitHub PagesはデフォルトでJekyllを介するため、Markdownファイルが混在
しても問題にならないよう `docs/.nojekyll` を配置し、静的ファイルを
そのまま配信する。）

## データフロー

1. ページロード時に `fetch('./data/population_by_age.csv')` … 実際には
   Pages配信ルート(`docs/`)からの相対パスでリポジトリ内 `data/` を参照する
   必要があるため、`docs/data/population_by_age.csv` へのシンボリック配置
   （またはビルド時コピー）を行う。運用上は、GitHub Actionsの月次ジョブが
   `data/population_by_age.csv` を更新した際、同じジョブで
   `docs/data/population_by_age.csv` にもコピーするステップを追加する。
2. PapaParseでCSVをパースし、`{year_month, age, male, female, total}[]` の
   配列をメモリに保持する。
3. 年月セレクタ（`<select>` or スライダー）で選択された年月のデータを
   フィルタし、Chart.jsのデータセットを更新する。
4. 推移グラフは年月ごとに年齢区分を集計（0-14 / 15-64 / 65+）した系列を
   一度だけ計算し、全期間分を描画する。

## エラーハンドリング

- CSV取得失敗（404、ネットワークエラー）: 画面上部に
  「データを読み込めませんでした。しばらくしてから再度お試しください。」
  を表示し、それ以上の処理は行わない。
- CSVは空/該当年月データなし: 「表示できるデータがありません」を表示。
- 個別行のパース失敗（数値でない等）はその行をスキップし、コンソールに
  警告を出す（画面には表示しない）。

## テスト・確認方法

- ローカルで `python -m http.server` 等を使い `docs/` を静的配信して
  ブラウザで表示確認（年月切り替え、グラフ更新、サマリー数値の正しさ）
- 実データが少ない間はダミーCSV（2〜3ヶ月分）で動作確認
- GitHub Pages有効化後、実URLでの表示確認

## 既知の制約

- CSVが将来的に大きくなった場合（目安: 数MB超）、年ごとファイル分割や
  サーバーサイド集計を検討する。現状のデータ量（月次×年齢0-105+×男女）
  では数百KB程度に収まる見込みのため対象外。
